SabzTar Android Source

1) Open this folder in Android Studio.
2) Let Gradle Sync finish.
3) Build > Build APK(s)
4) The debug APK will be in:
   app/build/outputs/apk/debug/app-debug.apk

Features in this source:
- No login screen
- Persian RTL UI
- Home dashboard
- Daily calories/macros/water
- Meal cards
- Food search with sample Iranian foods
- Food nutrition details
- Weight logging
- Profile/goal screen
- Jetpack Compose
